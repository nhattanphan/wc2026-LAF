# World Cup 2026 Prediction Competition

A live-updating prediction competition platform where lab members can predict tournament outcomes and compete for the highest score.

## Competition Rules

### Prediction Mechanics
- **Select 10 Nations**: Each participant picks 10 nations they believe will perform well
- **Rank 1-10**: Rank your selected nations from 1 (best) to 10 (worst)

### Scoring System
- **Win**: x3 multiplier
- **Draw**: x1 multiplier
- **Loss**: x0 (no points)
- **Knockout Stage**: Multipliers increase for matches in knockout rounds

### Features
- Real-time leaderboard updates
- Live match results integration
- Dynamic scoring calculation
- Historical performance tracking
